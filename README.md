# FREERIDE Frontier Radar

[打开公开 DEMO](https://lancewang1.github.io/freeride-frontier-radar/)

面向一级市场技术研究的可交互工作台：公开论文信号 → 有出处的技术判断 → 反证 → 买方与单位经济性 → 30天验证计划。

本轮研究日期：2026-10-23。三个待验证方向：在线审计路由、跨网关撤销完成证明、科学仪器异常处理。排序依据是验证可行性，**不代表全市场最优、低拥挤已获证实或投资推荐**。

## 运行

无需依赖安装，无需模型密钥。Python 3.10+：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

访问 http://localhost:8000 。不要直接双击 HTML，浏览器会限制 JSON 加载。

真实公开信号采集：

```sh
python scripts/collect.py
python scripts/test_data.py
```

采集使用 arXiv Atom API，每方向最多6条，间隔3秒；按来源URL去重，保留最多200条，记录错误并保留旧数据。版本不同的 arXiv URL 视为不同记录。新记录只进入 `pending.json`，不会自动生成研究判断。可在操作系统定时任务中执行；当前未安装任务。Actions (optional template) 的手动采集工作流仅生成供下载的 artifact，不自动提交或部署待研内容。

## 可用功能

- 三方向研究卡片、方法与限制、逐条页码出处、替代方案。
- 功能型产业链图谱；上下游CR5缺失时明确未知。
- 可编辑客户数、年费、渗透率和增长率的情景测算。
- 浏览器 localStorage 复核记录；Markdown 备忘录导出。
- 真实公开来源待研队列；来源PDF哈希用于记录本轮读取版本。

## 数据与模型边界

研究由当前助手研读公开材料后写成，未连接外部模型 API。核心三篇论文的方法、实验与限制已核对，旁证阅读深度在 `data.json` 单独标记。作者实验未独立重跑。仓库README可访问不等于代码可用性或商用许可已通过审查。

市场容量、观测 CAGR、上下游 CR5、融资拥挤度尚无充分数据。所有市场计算输入均为演示假设；没有用更宽行业TAM替代细分市场，没有用论文热度、stars替代资本关注或收入份额。

公开页面是静态研究快照，不会在浏览器后台自动抓取或分析。复核只存当前浏览器，不同步到GitHub。导出使用预置市场假设，不包含页面临时修改的测算输入，文件中明确标记。

## 研究与工程检查

运行 `python scripts/test_data.py` 校验证据引用及采集URL白名单。页面需通过桌面与移动浏览器检查、市场计算检查、复核持久化、导出与控制台检查。见 [研究备忘录](RESEARCH.md) 与 [验证记录](VALIDATION.md)。

本仓库独立构建，仅发布公开资料链接、有限元数据及原创研究。不含客户材料、基金配置、原始论文PDF、本机数据库、密钥或个人文件路径。

什么已经可用

三个方向深研、逐条出处、产业链、市场假设计算、30天验证计划、浏览器本地复核记录、Markdown 导出、真实 arXiv 信号采集与去重。

如何持续运行

本地执行 python scripts/collect.py，然后 python -m http.server 8000。脚本每次更新 pending.json；可由系统任务定时触发。GitHub Actions (optional template) 支持手动采集，产物作为 artifact 下载，不会自动发布未经复核材料。

尚未成立的结论

没有核验融资拥挤度、客户采购与收入，因此不标记“被低估”。市场容量、CAGR、上下游CR5暂无可比观测数据。页面测算均为可编辑假设。

公开版边界

仅含公开来源与原创分析，不含客户材料。复核记录只保存在当前浏览器。无云端同步、登录、后台模型或全天候任务；关闭本地服务后不会继续采集。

筛选规则

候选须具备明确新机制、可测的增量收益和可执行的证伪实验。优先低成本验证，再评估跨客户复用、付费意愿及平台替代风险。三个方向从先前主题筛选进入此轮深研，当前排序是研究判断，不是统计评分。

下一阶段的数据要求

关注度需固定关键词与对照主题，按月记录论文/独立团队、代码贡献者、融资轮次及金额、产品发布和招标采购；区分技术活动与资本拥挤。至少建立一个可比窗口后再判断变化，不用单日搜索结果下结论。
